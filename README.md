# Tessela

Browse and download ready-made QGIS style "themes" (a set of layers with
matching colors, symbols and labels) directly from the Plugin toolbar, with
a real preview rendered by QGIS itself before you download anything.

- Loads the list of published themes from a public GitHub repository (no
  account or login needed).
- Shows a full preview image for each theme, with mouse-wheel zoom and
  click-and-drag panning.
- Search box to filter by name or category.
- Free themes download instantly, straight from the button.
- Paid themes open the seller's checkout page (Gumroad/Payhip) in your
  browser; the file is delivered there.

This plugin only *reads* public data — it never asks for any personal
information and does not require an account.

## Como funciona (PT-BR)

Este plugin mostra "temas" de estilo prontos para o QGIS (conjuntos de
camadas com cores, símbolos e rótulos já configurados), com uma prévia real
renderizada pelo próprio QGIS. Temas gratuitos baixam direto pelo botão;
temas pagos abrem a página de compra no navegador.
